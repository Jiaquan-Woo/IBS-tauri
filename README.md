# IBS-tauri

#### 介绍
利用AI编写的基于IBS.js的批量可视化蛋白结构域软件。以Tauri为框架。IBS.js 详见官网https://ibs.renlab.org/#/home 。
example文件夹内包含了示例excel文件，直接在软件中加载即可预览实现效果。

#### 软件架构
以Tauri 2.0为框架开发图形用户界面，可视化功能来自IBS.js


#### 安装教程
直接下载ibs-tauri.exe，完成后双击软件即可运行

#### 使用说明

软件首页点击“Open File”，选择记录了蛋白结构域信息的excel表格（.xlsx格式）即可。表格的格式可见examole文件夹中的AtMCTP346_domain_table.xlsx文件。
